JIS キーマップ比較

Windows の現行設定と MacBook Pro JIS 向けの設定を、このページで見比べます。レイヤーを選び、キーを押すと割り当ての詳細が表示されます。

Windows 側の基準: Windows の図は Change Key と現在の AHK を反映しています。README の要約とは RCtrl+A、Home / End の割り当てに差があるため、実装コードを基準にしています。
